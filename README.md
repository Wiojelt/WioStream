# WioStream

Wiojelt CloudStream and Nuvio extension hub. The canonical site is [wiojelt.github.io](https://wiojelt.github.io/); this repository also serves the project path at [wiojelt.github.io/WioStream/](https://wiojelt.github.io/WioStream/).

## Local preview

Open `index.html` in a browser, or run:

```powershell
python -m http.server 8765
```

## GitHub Pages

The site is static. GitHub Pages serves the `main` branch root. The `wiojelt.github.io` user-site repository contains the same `index.html`, `site.css`, `site.js`, and `assets/logos/LiveHub.svg` files. Plugin logos are loaded from their versioned GitHub assets.
